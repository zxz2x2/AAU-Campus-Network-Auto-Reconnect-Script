校园网自动登录重连——通用独立版使用方法（Windows）

一、适用范围和准备条件
1. 适用于 Windows 10/11，需安装 Microsoft Edge。
2. 需要自行安装 Node.js 22 或更新版本，建议选择官方当前 LTS 版。
   官方下载地址：https://nodejs.org/en/download
   选择适合电脑架构的 Windows 安装程序，保留 npm 和添加 PATH 的默认选项。
3. 安装 Node.js 后重新打开命令提示符，分别输入 node -v 和 npm.cmd -v。
   两条命令都显示版本号后再安装脚本。
4. 首次安装脚本需要联网下载 playwright-core 依赖，可先手动登录校园网或连接手机热点。
5. 支持常见账号密码网页登录；特殊表单需要配置，验证码、短信、扫码不能保证自动完成。
6. 此程序不绕过学校夜间断网限制。以下步骤只适用于“通用独立版”配套压缩包。

二、解压与安装
1. 将 CampusReconnect-通用独立版.zip 右键“全部解压缩”，不要在压缩包内直接运行。
2. 将全部文件放在固定目录。
3. 同目录应有 install.cmd、install.ps1、test.cmd、test.ps1、reconnect.cjs。
4. 双击 install.cmd。程序会下载依赖到本目录的 node_modules，并检查 Edge 启动。
5. 环境检查通过后依次输入：
   学校登录页完整网址（以 http:// 或 https:// 开头）；
   每天登录时间（24 小时制 HH:mm，直接回车默认 06:00）；
   额外可信认证主机名（多个用英文逗号分隔，没有则回车）；
   校园网账号和密码（密码输入不显示）。
6. 可信主机只填写学校确实使用的域名或 IP，不含协议、路径、端口。
   例如门户跳转到另一认证服务器，必须额外配置它，脚本才允许在那里填写密码。
7. 显示 Installed 才表示任务安装成功。任务名称为 Campus-AutoReconnect。
8. 后续不要移动安装目录、node_modules 或 Node.js 安装目录。
9. 升级旧版时，请先在任务计划程序中禁用 AHAU-Campus-Reconnect，避免两个任务同时运行。

三、手动测试
1. 确认已连接校园 Wi-Fi 或校园网网线，双击 test.cmd。
2. Already online 表示联网检测已通过，不再提交登录。
   如需验证真正的自动填写和提交，可先从校园门户手动注销再测试。
3. 需要认证时会打开可见的 Edge，尝试识别账号密码框并登录。
4. SUCCESS: Internet verified. 表示登录后通过联网检测。
5. 测试只尝试一次，结束前保留浏览器约 30 秒供查看。
6. 通用版默认没有固定凌晨禁用时段。如学校夜间断网，可按第五节配置 blockedHours。

四、每天自动运行
1. Windows 时间和时区应正确，国内学校一般设置为北京时间。
2. 程序每天在安装时指定的本地时间运行，不是全天持续监控。
3. 电脑必须开机、安装任务的 Windows 用户已登录，锁屏可以。
4. 必须已经连接校园 Wi-Fi 或网线；脚本不负责自动选择和连接 Wi-Fi。
5. 任务请求从睡眠唤醒，但依赖硬件和电源设置；不能让完全关机的电脑开机。
6. 默认失败每 60 秒重试，最多 3 次，另加网页加载耗时，总执行上限 1 小时。
7. 错过运行时间时，会在系统允许后补运行。
8. 安装完成后无需手动打开 Node.js 窗口。

五、不同学校的表单适配
安装后用记事本打开 school.json。它是 JSON 文件，必须保留英文双引号和正确标点。
portalUrl：登录页网址。避免固定旧设备 IP/MAC 的过期链接。
allowedHosts：允许填写密码的认证主机名数组，仅添加可信学校认证服务器。
usernameSelector：账号框 CSS 选择器；空字符串自动识别。
passwordSelector：密码框 CSS 选择器；空字符串自动识别。
submitSelector：登录按钮 CSS 选择器；空字符串自动识别。
beforeSubmit：填写账号密码后、提交前执行的操作数组，可配置勾选、选择和点击。
  示例仅供说明，需要替换为本校真实元素：
  [{"type":"check","selector":"#agree"},{"type":"select","selector":"#operator","value":"实际选项值"}]
blockedHours：默认 null；若学校 0 点至 6 点断网，改为 {"start":0,"end":6}。
  起点包含、终点不包含，可跨午夜；使用不同的 0-23 整数。
maxAttempts：尝试次数，1-30，默认 3。
retrySeconds：重试间隔秒数，至少 30，默认 60。

不确定选择器时，请提供不含密码的登录页截图及 portal-structure.json 以便适配。
不能保证任意学校只改网址就能成功。

六、任务、日志和密码管理
1. Win+R 输入 taskschd.msc，打开任务计划程序。
2. 在任务计划程序库找到 Campus-AutoReconnect，查看下一次运行时间和上次结果。
3. reconnect.log：运行进度和失败阶段。
4. portal-structure.json：测试生成的表单结构，不收集输入框中的值。
5. school.json：学校网址、表单和重试配置。
6. runtime.json：本机 Node.js 和依赖路径。
7. credentials.xml：本机当前 Windows 用户加密的凭据。不要发送或分享。
8. 修改账号或密码：重新运行 install.cmd，会重新要求输入并保存。
   注意重新安装也会重置 school.json，自定义配置请先备份，在安装后按需恢复。
9. 修改每日运行时间：在任务计划程序中调整触发器，或重新安装。
10. 将文件分享给别人时，只分享原始压缩包；不要分享安装后的凭据和本机配置。
    每个人都需在自己的电脑上安装并输入自己的账号密码。

七、常见问题
1. 提示 install.ps1 不存在：请全部解压并确认文件齐全，不要在压缩包里运行。
2. 提示找不到 Node.js/npm：安装官方 Node.js，确认 PATH 后重新打开安装窗口。
3. 依赖下载失败：先联网，检查代理或学校网络限制，再重试。
4. 找不到 Edge 或浏览器启动失败：安装/更新 Edge，保存完整错误提示用于排查。
5. 出现系统安全策略拦截：不要关闭安全功能，请保留提示信息并排查被拦截组件。
6. 只打开页面但不登录：检查可信认证主机、输入框、登录按钮及协议/运营商选项。
7. 安装成功但定时不运行：检查任务、登录用户、系统时间、开机和睡眠唤醒设置。
8. 更换电脑：重新安装并输入账号密码，旧电脑的加密凭据不能直接用于新电脑。
9. 移动目录或升级 Node.js 后失效：在固定目录重新运行 install.cmd 更新路径。
10. 需要反馈时提供测试窗口文字、reconnect.log 和 portal-structure.json；截图隐藏密码。

八、卸载
1. PowerShell 中运行：
   Unregister-ScheduledTask -TaskName 'Campus-AutoReconnect' -Confirm:$false
2. 确认任务已删除后，可删除脚本安装目录。
3. Node.js 如被其他软件使用，不需要卸载。
